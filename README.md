# IM SDK ios 0.1.1

本分支保存 ios 0.1.1 的历史源码与对应交付资料。当前各平台最新版见 [main](https://github.com/use032026/IMSDK/tree/main)。

[下载完整交付包](https://github.com/use032026/IMSDK/releases/download/ios-v0.1.1/IMSDK-iOS-0.1.1.zip) · [发布记录](https://github.com/use032026/IMSDK/releases/tag/ios-v0.1.1)

移动端共享源码位于 `packages/im_sdk`，原生适配位于 `native`，宿主样例位于 `examples`。原始源码快照说明见 [docs/SOURCE_README.md](docs/SOURCE_README.md)；恢复来源与范围见 [VERSION.json](VERSION.json)。原生大二进制通过 Release 提供，Git 目录不包含完整 `binary/` 或 `maven/`，请从完整包获取依赖。

0.1.1 由 0.1.0 完整源码基线叠加 0.1.1 保存快照恢复。Dart lib 和两端原生运行时代码的摘要与当时验证报告一致；未变化的资源及工程辅助文件来自基线。此分支未重新构建，不把历史报告视作本次重新验收结果。
