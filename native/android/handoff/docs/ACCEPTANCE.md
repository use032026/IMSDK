# Android SDK 验证与接入验收

SDK：`0.1.2` · 更新：2026-10-28

## 本轮原生二进制与真实服务验证

本版默认示例已预置与 Web 相同的真实服务，启动自动进入登录 / 注册，无需修改配置。验收使用新构建的 SDK 二进制和实际交付样例源码，在 API 35 模拟器中的 Java 原生宿主 上通过界面完成注册、自动登录、重新登录、好友搜索 / 申请与接受、会话列表及单聊 / 群聊收发。真实服务写操作与构建 / 独立消费分别记录，结果以本包 MANIFEST 为准。

本轮使用两个新的主要测试账号，iOS 与 Android 互为对端。已有专用辅助账号仅用于补齐两端好友申请及接受角色，不冒充本轮新注册。两个主要账号各自创建一个仅含双方的新群；按单聊两条、两群各两条共六条本轮唯一消息逐项核验。独立身份直接读取服务端记录，核对真实发送者、正文、消息序号、群所有者及精确成员；界面按钮成功或本地气泡本身不作为送达证明。

包内仅包含本次授权的公开服务连接，不含测试账号、密码、token 或生产签名。iOS / Android 真机、媒体、推送、后台恢复及生产发布不由本轮模拟器与文本流程结果推定；旧版日志不能替代本版二进制和本轮新增业务的验收。

## 接入方验收清单

| 项目 | 接入方应确认 |
| --- | --- |
| 依赖与打包 | 完整 Maven 仓库可解析；Debug / Release 构建、混淆、ABI、包体与已有依赖兼容 |
| 默认预接服务 | 原样安装启动即可注册 / 登录，无需修改配置；接入其他环境仍可覆盖配置，包内无账号、token 或服务器管理密钥 |
| 隐私 | 未取得同意不初始化；取得同意后才传 `privacyConsentGranted=true` |
| 注册与好友 | 无空间选择，注册后进入实际空间；搜索、申请、接受 / 拒绝及选好友新建群可用 |
| 账号密码 | 个人明确使用 `lpp_id`；企业固定 tenantCode；成功、错误密码、验证码及会话失效符合后端策略 |
| 单聊 | 两个真实账号双向收发；逐项核对 UI 与独立对端；重入后历史一致 |
| 群聊 | 授权成员双向收发；新消息与历史正确；无跨群、跨账号或跨空间混入 |
| 生命周期 | 返回 / 重开、旋转、Activity 重建、切后台、系统回收与重新进入行为正确 |
| 账号切换 | logout 成功后再切换；外部凭证与通知目标属于同一账号 / 空间；过期凭证可恢复 |
| 客服 | 真实企业 / 服务账号路由正确；queued / unknown 不进入聊天；active 才可进入；账号变化时拒绝旧请求 |
| 真机媒体 | 相机、相册、文件、麦克风、拒绝权限、选择器中断与重试均可用 |
| 推送 | 宿主厂商接入、通知权限、前后台与冷启动跳转、账号 / 空间校验 |
| 性能与资源 | 启动耗时、常驻内存、聊天内存、长会话、shutdown 后释放、弱网恢复 |
| 生产发布 | 宿主 applicationId、签名、环境、日志脱敏、权限说明与隐私材料完成 |

## 建议记录方式

每次宿主验收记录 SDK 版本、交付包校验值、宿主版本、系统 / 设备、环境、用例结果和脱敏证据。真实服务收发同时核对发送方、独立接收方与重开后的历史；页面打开成功、按钮点击或仅出现本地消息气泡不足以单独证明消息已到达对端。
