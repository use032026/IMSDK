# 35语 SDK 交付与发布

本次从当前源码重建 iOS/Android0.1.3、Web0.1.6，公共语言资源版本0.3.0。2026-10-30 已提交源码、建立平台版本分支与标签，并将三份完整 ZIP 及 SHA256 发布至对应 GitHub Release。main 的版本与下载索引同步更新，旧版由历史分支和 Release 保留。

每个包的 `localization/` 包含语言清单、公共资源生成收据和专属缺译覆盖记录。iOS App.framework和Android Flutter AAR另携带相同的 `packages/im_sdk/assets/l10n/sdk_locale_manifest.json`；原生共享翻译由Flutter编译为代码，不要求运行时读取ARB。Web的IIFE/ESM/CJS和npm包携带已生成词库与LOCALIZATION.json。

35种语言为：zh-CN、zh-TW、en、ja、ko、vi、ar、bg、cs、da、de、el、es、fi、fil、fr、hi、hr、hu、id、it、ms、nb、nl、pl、pt-BR、pt-PT、ro、ru、si、sk、sv、th、tr、uk。

每语保留1040个公共ARB词条；原六语值和公开本地化接口保持一致。SDK/Web专属缺译明确回退英语，详见包内sdk_coverage.json；法律正文保持原选择和回退逻辑。语言码接受和资源完整不代表全部历史页面、字体、译文质量或法务正文都已完成35语验收。

宿主在初始化设置locale，也可调用updatePresentation更新locale和themeMode。pt/pt-BR表示巴西葡语，pt-PT表示葡萄牙葡语；语言变化保留当前账号、路由和输入。用户消息、昵称和宿主自定义标题保持原文。

本地打包入口为 `scripts/package_localization_handoff.py`，需要当前源码、版本、语言清单、二进制与独立消费结果匹配。原有真实服务发版脚本及其门槛保留；本次MANIFEST显式使用localization-rebuild范围，不沿用旧版实服通过结果。

本轮构建、架构、消费检查、ZIP完整性和清理结果以 `logs/l10n35-handoff-20261029/validation.json` 及各包MANIFEST.json为准。未执行本版真实后端注册/好友/群聊写操作、真机或生产发布验收。MediaServiceClient和chat-im-cs未被本次打包修改。

本轮三包已逐文件验证，iOS共2879文件、Android830文件、Web31文件；最新外部校验汇总为 `dist/SHA256SUMS`。独立消费包括iOS六组Swift/ObjC链接及UIKit模拟器/未签名设备编译，Android Maven-only宿主与Java/Kotlin及三ABI符号剥离复现，Web35语浏览器和npm三模块/声明消费。原生宿主未实际启动，浏览器使用隔离夹具，没有本版真实服务写操作。

包内 `remotelyPublished` 等字段是 2026-10-29 打包时的原始快照，ZIP 字节未为发布而改写；当前发布状态以 GitHub Release 与 `dist/versions.json` 为准。源码和本次上传工作未触发重新构建。
