# H5 接入验收与已验证范围

SDK 版本：0.1.5。文档整理日期：2026-10-28。

## 本轮验证范围

Web 0.1.5 的验收对象是包内预接真实服务的默认页面，通过 Chrome `file://` 直接打开，使用两个新专用账号完成注册、自动个人登录、退出后重新登录、好友申请与接受、会话列表、单聊及新建双人群双向文本收发。两个独立浏览器身份核对页面显示，并以独立身份读回确认真实发送者、群成员和消息序号。没有测试时注入连接配置、API 响应模拟、鉴权绕过或服务策略修改。具体结果与摘要见本包 MANIFEST。

## 一、资源与环境

- [ ] 使用交付的完整 npm 包或全量 `sdk/im-sdk.js`，文件版本与校验值一致。
- [ ] SDK 静态资源正常返回 JavaScript，页面未因错误资源路径得到 HTML。
- [ ] 宿主完成用户同意流程；环境、空间和企业码由接入方配置，最终用户不填写内部接入字段。
- [ ] 容器已挂载、具有明确高度，组件卸载与整页销毁的资源归属清楚。
- [ ] 在实际部署 Origin 上，API 的预检、鉴权请求及网关 negotiate / WebSocket 通过。
- [ ] 反向代理保留所需路由与 Upgrade，CSP 未阻止 SDK 资源、连接或 UI 样式。

## 二、登录与账号生命周期

- [ ] 注册按服务端渠道及验证要求进行，无空间选择；进入实际空间且仅一个活跃会话。
- [ ] 搜索好友、申请、接受 / 拒绝后状态与服务端一致，可选择好友单聊或新建群。
- [ ] 打开页面未登录直接显示登录 / 注册，已有有效 IM 登录态直接显示会话列表；没有要求最终用户填写技术配置。
- [ ] 未配置服务时仍可查看登录 / 注册页；不向占位服务发送账号，宿主配置就绪后可正常使用。
- [ ] 正确账号密码可登录并进入当前账号的会话列表。
- [ ] 错误密码、需要安全验证及网络失败时有明确反馈，没有错误进入聊天。
- [ ] 若使用外部 IM 凭证，凭证来自宿主受信后端，用户 / 平台身份 / 空间一致；错配或过期凭证被拒绝。
- [ ] 关闭聊天界面再重开，仍是本页当前账号；关闭界面未被误当成退出账号。
- [ ] 独立登录模式宿主退出账号时调用 `logout()`，旧会话和旧消息不再出现在界面中。

### 宿主显示设置（新增源码构建）

- [ ] 宿主初始化和运行中更新 `themeMode` / `locale`；SDK 没有另加用户设置入口，不需要重新初始化。
- [ ] light / dark 均可用；system 随媒体设置实时切换，显式主题不被系统覆盖。
- [ ] 简体、繁体、英、日、韩、越六语的登录、注册、消息列表、聊天、客服、错误、占位和可访问标签完整更新；后端消息和用户名原文保持。
- [ ] 运行中切换保留账号、路由、表单值、聊天草稿及滚动位置；没有新增认证或取票请求。
- [ ] `locale: system` 响应浏览器语言变化；显式语言忽略同样事件，无支持语言时回退简体中文。
- [ ] 非法主题或语言与另一个有效字段一起更新时，整份拒绝且配置不变；规范化支持脚本优先和地区别名。
- [ ] 关闭后语言监听与文案订阅已释放，宿主账号同步模式仍不弹 SDK 登录界面。

### 宿主账号同步模式（新增源码构建）

- [ ] `hostManagedAuth: true` 已启用，provider 在挂载前绑定；稳定 `hostUserId`、每次登录变化的 `sessionId` 和可信后端 IM 票据具备真实来源。
- [ ] 宿主已登录而 SDK 未登录、accessToken 过期、自身 refreshToken 失效三种入口均静默进入会话列表，全程没有 SDK 登录表单、登录弹窗或列表首屏转圈。
- [ ] 宿主退出或 A→B 切换通知立即隐藏旧账号内容、清理内存会话和中止旧请求；不依赖用户重新打开页面才生效。
- [ ] 取票中、资料请求中或会话请求中退出，旧结果不能重新激活账号或把 A 的内容写进 B。
- [ ] 刻意遗漏变化通知后，再打开会话列表或恢复前台会复查宿主状态；快照读取失败时不继续展示未经确认的旧账号内容。
- [ ] 取票错误只显示页面内重试；并发入口、过期请求合并取票；恢复后仍无登录 UI。
- [ ] 同账号再次打开先显示内存缓存，退出/换号后旧缓存不可见。分别记录预热入口和冷入口可交互耗时，不能只凭无弹窗宣称网络已完成。
- [ ] provider 替换、显式退出和 shutdown 后迟到的票据无法复活账号；shutdown 取消订阅。
- [ ] 模拟 provider / 模拟后端结果与真实宿主账号映射、真实换票联调分别记录；构建或契约测试不代替真实集成验收。
- [ ] 切换账号时，旧请求的迟到结果不会覆盖新账号数据。
- [ ] 整页刷新后的登录恢复符合宿主设计；没有误认为 SDK 已持久保存凭证。
- [ ] 页面 / 组件不再使用实例时调用 `shutdown()`；重新打开时不复用已释放实例。

## 三、单聊

- [ ] 使用服务端允许联系的测试好友，从好友列表或宿主授权入口进入单聊。
- [ ] 历史和分页正常，发送者方向及中文、空格、换行显示正确。
- [ ] 从 H5 界面发送带唯一标记的文本；独立对端或服务端读回确认该消息 ID、真实发送者和序号。
- [ ] 由对端发送唯一回复；确认回复持久化，并在当前 H5 页面实际显示。
- [ ] 记录实时连接状态；若验证实时送达，应记录对应会话的事件与页面更新，不能仅凭本地乐观气泡认定送达。
- [ ] 网络结果不明时，同一份未修改草稿复用发送 ID，确认没有重复持久化。

## 四、群聊

- [ ] 先核对测试群、账号成员身份和服务端允许的操作范围。
- [ ] 群历史及分页正常，当前账号与其他成员的消息方向正确。
- [ ] H5 发送唯一标记文本，独立对端确认真实发送者及持久化。
- [ ] 对端回复已持久化，并在 H5 群聊界面实际显示。
- [ ] 无权限或被禁言等服务端拒绝能够反馈；没有通过前端绕过群权限。

不要为完成验收擅自扩大测试群成员或修改业务权限。使用既有授权测试范围，必要的建群 / 权限准备由业务负责人安排。

## 五、页面恢复与展示

- [ ] 后台返回或断网恢复后，列表 / 当前聊天能补取快照，未漏显对端回复。
- [ ] 浏览器离开再返回时，界面状态符合是否实际命中页面返回缓存的结果，没有持有已释放实例。
- [ ] 收到消息更新或撤回后，原内容不再错误显示，未发送草稿保留。
- [ ] 长标题、长消息、空列表、错误提示和窄屏容器能正常操作。
- [ ] 若验收已读，只有实际可见并阅读到的消息被提交，服务端读回结果与预期一致。

## 六、按实际投放范围追加

这些条目只在应用实际使用对应环境 / 功能时执行，并单独记录结果。

- [ ] **手机 Safari / WebView**：真机软键盘打开后输入框和发送按钮可见，连续发送不会异常收起键盘；安全区、旋转、滚动和页面挂起恢复正常。
- [ ] **微信内置浏览器**：本轮暂不执行，状态保留为未验收。后续投放该环境前，在真实微信版本中验证登录、单群双向收发、页面返回及键盘；UA 模拟不能替代。
- [ ] **企业空间**：固定企业码与账号真实成员资格一致，个人与企业身份不会混用。
- [ ] **客服入口**：`queued` / `unknown` 显示相应状态；只有 `active` 且存在真实会话 ID 时才能进入消息页。人工接管和回复另行核验。
